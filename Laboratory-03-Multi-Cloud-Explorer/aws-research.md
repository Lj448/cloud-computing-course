# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform from Amazon. It provides many services that businesses can use to run applications, store data, manage networks, and build other cloud solutions.

## Global Infrastructure

AWS has cloud infrastructure in different parts of the world. It uses Regions and Availability Zones to place resources in different locations. This helps businesses choose locations that are closer to their users and helps improve availability. 

## Cloud Management Console

The AWS Management Console is a website where users can access and manage AWS services. Users can use the console to create resources, check services, manage users, and monitor their cloud resources.

## Four Core Services

### 1. Amazon EC2

Amazon EC2 provides virtual servers that can be used to run applications.

### 2. Amazon S3

Amazon S3 is a storage service used to store files and other types of data.

### 3. Amazon VPC

Amazon VPC allows users to create and manage a private network for their AWS resources.

### 4. AWS IAM

AWS IAM helps manage users, permissions, and access to AWS resources.

## Three Advantages

1. AWS provides many different cloud services for different business needs.
2. AWS has infrastructure in many locations around the world.
3. AWS allows businesses to create and change cloud resources based on their needs.

## Typical Enterprise Use Cases

Businesses can use AWS to host websites and applications, store company data, run databases, create backup systems, and support large online services.
