# Azure Research

## Brief Overview

Microsoft Azure is a cloud platform created by Microsoft. It provides services that businesses can use to run applications, store data, create networks, and manage computer resources.

## Global Infrastructure

Azure has cloud infrastructure in many parts of the world. It uses regions and availability zones to help businesses place their resources closer to their users and improve reliability.

## Cloud Management Console

The Azure portal is a web-based tool used to create and manage Azure resources. Users can use it to manage virtual machines, storage, networks, databases, and other cloud services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can run Windows or Linux applications.

### 2. Azure Blob Storage

Azure Blob Storage is used to store large amounts of files and other unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network allows users to create a private network for their applications and virtual machines.

### 4. Microsoft Entra ID

Microsoft Entra ID manages user identities and access to cloud resources and applications.

## Three Advantages

1. Azure works well with Microsoft products and technologies.
2. Azure provides cloud services for many different business needs.
3. Azure supports security, reliability, and hybrid cloud environments.

## Typical Enterprise Use Cases

Companies can use Azure to run business applications, host websites, store company files and data, support Windows Server systems, create backup solutions, and connect existing company systems to the cloud.
