# GCP Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud platform from Google. It provides services that businesses can use to run applications, store data, manage networks, and build cloud solutions.

## Global Infrastructure

Google Cloud has infrastructure in different parts of the world. It uses regions and zones to help businesses run their resources in suitable locations and improve the availability of their applications.

## Cloud Management Console

Google Cloud Console is a web-based tool used to manage Google Cloud resources. Users can create, monitor, and manage services such as virtual machines, storage, networks, and databases.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can be used to run applications and other workloads.

### 2. Cloud Storage

Cloud Storage is used to store files and other types of data in the cloud.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking for virtual machines and other cloud resources.

### 4. Cloud Identity

Cloud Identity helps organizations manage users and access to cloud applications and services.

## Three Advantages

1. Google Cloud has strong tools for Artificial Intelligence and Machine Learning.
2. Google Cloud provides services for building and running applications at different scales.
3. Google Cloud provides strong support for containers and Kubernetes.

## Typical Enterprise Use Cases

Businesses can use Google Cloud to host applications, store company data, run virtual machines, develop AI and machine learning systems, and deploy container-based applications.
