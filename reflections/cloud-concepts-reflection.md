# Cloud Concepts Reflection

Cloud computing is part of my daily life even if I do not always notice it. Three cloud services that I use regularly are Google Drive, Netflix, and GCash. These applications help me study, enjoy entertainment, and manage my money more easily.

Google Drive is an example of **Software as a Service (SaaS)** because I can store, open, and share my files online without installing or managing any servers. It uses a **Public Cloud** because many users can access the service through the internet.

Netflix is also a **Software as a Service (SaaS)** because I only need to log in and watching k-dramas or movies. I do not have to manage the system that runs the service. It is also a **Public Cloud** because it is available to anyone with an account and an internet connection.

GCash is another **Software as a Service (SaaS)**. It allows me to send money, pay bills, and buy mobile load using my phone. I consider it a **Public Cloud** because customers use it through the internet while the company manages the system and keeps the service available.

I also learned why Git and GitHub are important when working on cloud projects. Version control helps keep track of changes made to files and prevents important work from being lost. If a mistake happens, previous versions can be restored. GitHub also makes teamwork easier because different people can work on the same project without replacing each other's work. Team members can review changes, share ideas, and keep the project organized. I realized that version control is an important tool because it helps developers work more carefully, avoid errors, and manage cloud projects more effectively.
